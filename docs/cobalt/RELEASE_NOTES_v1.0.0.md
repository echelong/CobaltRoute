# CobaltRoute v1.0.0

CobaltRoute v1.0.0 is the first public CobaltRoute release.

**Built by Cobalt.**

## Runtime foundation

CobaltRoute v1.0.0 is based on OmniRoute 3.8.51 and intentionally preserves
the inherited `omniroute` package and CLI identifiers for compatibility.

The release additionally provides the `cobaltroute` CLI alias.

## CobaltRoute intelligence stack

- V1 — persistent task-aware adaptive routing.
- V2 — Router Brain automatic outcome learning.
- V3 — deterministic coding verification feedback.
- V4 — reset-aware free quota intelligence.
- V5 — verified multi-model racing.
- V6 — automatic free-model discovery and qualification.
- V7 — request, response, tool, and protocol compatibility repair.
- V8 — hybrid local and cloud routing.
- V9 — release identity, presets, benchmark, and release auditing.

The included deterministic benchmark is a routing-policy benchmark rather
than an LLM intelligence benchmark. It performs no external model calls.
